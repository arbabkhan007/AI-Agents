# Cottage Bakery v4 Spreadsheet

Enhanced Cottage Bakery business spreadsheet built with `openpyxl`.

## Files

| File | Description |
|------|-------------|
| `Cottage_Bakery_v4_ENHANCED.xlsx` | Working spreadsheet (all sheets editable) |
| `Cottage_Bakery_v4_ENHANCED_LOCKED.xlsx` | Locked version — password **`premium`** |
| `build_cottage_bakery.py` | Script that generates both files |

## Tabs

Instructions + Setup · Unit Conversion · Ingredients + Stock · Recipe Library ·
Recipe Calculator · Product List · Overhead Expenses · Startup Costs · Dashboard ·
Orders · Bookkeeping · Markets & Events · Customers · Analytics (BONUS)

## Features

- 14 tabs, ~3,300 live formulas, no circular references
- Unit conversion (g/kg/mg/oz/lb/ml/L/tsp/tbsp/cup/fl oz/pint/quart/gallon/pcs/dozen)
- Recipe Library (50-recipe capacity) + 3-recipe calculator
- Overhead monthly expenses with hourly & per-order rate auto-calc
- Startup costs with break-even months + chart
- Data validation dropdowns and conditional formatting
