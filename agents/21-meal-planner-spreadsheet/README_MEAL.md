# Meal Planner & Grocery List

Plan the week, shop the list, cook the food, waste less.

This workbook is a complete meal planning system in one Excel file: 36 tabs
covering recipes, meal planning, automatic grocery lists, pantry stock,
batch cooking, food waste, budgeting and nutrition. It is built for Excel
2010 and later, works in Excel, LibreOffice Calc and Google Sheets (upload
the .xlsx), and every sheet is protected so the formulas cannot be
overwritten by accident.

## What is in the box

- `Meal Planner & Grocery List.xlsx` - the workbook, filled with sample data
  so you can see how every tab works.
- `HOW_TO_USE_MEAL.md` - the step-by-step guide to setting it up.
- `SOURCE_CODE_MEAL.md` - the full Python source code that generated the
  workbook, for anyone who wants to change it or build their own version.

## How it works

1. **Recipes and ingredients.** Your recipe book, one row per recipe, with
   the ingredients, quantities and prices that make each dish.
2. **Meal Plan.** Pick the date, the slot and the recipe. The plan works
   out the nutrition, the cost, how the meal compares with the rest of the
   day, whether it is too soon after the last time you had it and whether
   it trips one of the household dietary filters.
3. **Grocery List.** Every planned meal is copied here automatically. The
   quantities are scaled to the servings you planned, reduced by what the
   pantry says you already have and grouped by aisle, with a price and a
   running total.
4. **Tracking.** Record what you spent, what you threw away and how the
   month is going. The Budget, Reports and Sustainability tabs do the
   rest.

## Sample data

The workbook ships filled with a working example:

- a household of 4 in the Midlands, with a GBP 120 weekly food budget
- 38 recipes across 8 cuisines, from a GBP 0.46 jacket potato to a
  GBP 3.27 salmon traybake
- 62 ingredients with prices, units and shelf lives
- 107 planned meals across 15 weeks
- 12 grocery shops, 38 waste rows and 13 leftovers

Every calculated cell shows its formula in the formula bar. Clear the
yellow input cells and type your own data - the grey calculated cells do
the rest.

## Rebuilding from source

The workbook is generated by Python, using XlsxWriter. If you have the
source code (`SOURCE_CODE_MEAL.md` or the `meal_planner_spreadsheet`
package):

```bash
pip install XlsxWriter openpyxl
python build_meal_planner_workbook.py        # filled workbook
python build_meal_planner_workbook.py --blank   # blank workbook
```

The build is deterministic: the same source produces the same workbook.
Every formula stays within the Excel 2010 function set - no XLOOKUP, no
FILTER, no dynamic arrays.

## Protecting your work

Every sheet is protected with the password `premium`, with the input cells
left unlocked so you can type in the yellow cells. To edit a formula or a
calculated cell, use **Review > Unprotect Sheet** and enter the password.

## Requirements

Microsoft Excel 2010 or later, LibreOffice Calc, or Google Sheets. Nothing
else - no add-ins, no macros, no internet connection.
