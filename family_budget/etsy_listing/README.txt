NOVALITY STORE — PREMIUM FAMILY BUDGET
ETSY LISTING PACK
=====================================

WHAT'S IN THIS FOLDER
---------------------
etsy_listing_kit.md   ..... The full Etsy listing: title, tags, description,
                           pricing, compliance tips.
tags.txt              ..... 13 primary tags + alternates + do/do-not notes.
images/               ..... 12 listing images (cover + feature shots + 2 marketing
                           composites). Use the cover as the thumbnail.
source/               ..... The source code that builds the spreadsheet:
                             * Novality_Family_Budget_source_code.txt (readable text)
                             * main.py + the Python modules (.py) — run `python3 main.py`
                               to regenerate the workbook.
Novality_Family_Budget_Premium.xlsx ..... The actual product.

HOW TO UPLOAD TO ETSY
---------------------
1. Create a new listing: type = "Digital download".
2. Paste the Title from etsy_listing_kit.md.
3. Paste the Description from etsy_listing_kit.md.
4. Add the 13 tags from tags.txt.
5. Upload images from images/ (Etsy accepts up to 10; pick the best).
6. Attach Novality_Family_Budget_Premium.xlsx as the downloadable file
   (you may need to zip it, or add it as the "digital file").
7. Set price per the pricing table, or add a bundled version.

PASSWORD / PROTECTION

Input (cream) cells are left editable so buyers can personalize.
